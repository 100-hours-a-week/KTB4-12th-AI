# 채팅 점검

배포한 서버의 `/healthz`와 인증된 `/readyz`에서 코드 버전과 저장소·검색 상태를 확인합니다. ready 응답만으로 추천 품질을 판단하지 않습니다.

신고·대화는 인증된 관리자 화면에서 필요한 범위만 확인하고, 목록의 마지막 cursor까지 조회합니다. 개인정보가 든 원문을 외부 모델이나 PR에 복사하지 않습니다. 문제를 합성 데이터로 재현해 수정·회귀·배포 확인을 마친 뒤 해결 처리합니다.

모델 호출은 허용된 예산 안에서 진행합니다. 기존 비용 계정이나 미확정 예약을 초기화·환급하지 않습니다. 이 원장은 실험 비용 기록이며 사용자 크레딧 정책과는 별개입니다.
