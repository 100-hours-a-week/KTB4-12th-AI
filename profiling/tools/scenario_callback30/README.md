# 프로파일링 코어 30개 상품 콜백 검증 — `tools/scenario_callback30/`

가상 수신자(엑셀)를 프로파일링 코어에 넣어 **입력 → 점수 책정 → 30개 추천 → 7.7 콜백**을 한 번에 보고 검사한다. 돌릴 때마다 화면에 결과가 나오고 `out/`에 엑셀·JSON이 남는다.

```bash
cd profiling
docker start profiling-ai-db && uv run alembic upgrade head      # DB 카탈로그(ai_catalog, BE 번호) 필요
uv run python -m tools.scenario_callback30.run                  # 두 모드(exclude · penalty) 모두
uv run python -m tools.scenario_callback30.run --modes penalty --top 10 --keep
uv run pytest tests/integration/test_scenario_callback30.py -q  # 같은 실행을 시험으로(실패 검사 이름을 보여 줌)
```

| 파일 | 역할 |
|---|---|
| `scenarios.xlsx` | **입력** — 사용자(비선호 · 취향 문장) · 리뷰(상품 · 별점 · 글) · 기대(검사). 엑셀을 직접 고쳐 사람을 늘리거나 기대를 바꾼다. 쓰는 법은 '설명' 시트 |
| `run.py` | 실행기 — 앱 전체를 서버 없이(TestClient) 띄워 7.6 을 보내고, **진짜 `HttpBackendPort`가 보내는 7.7 HTTP 요청**을 MockTransport 로 받아 기록 |
| `out/` | 결과(커밋 안 함) — `시나리오_결과_<시각>.xlsx` · `.json` |

## 무엇을 타나

7.6 POST → 202 → Supervisor 워커 → `pipeline.profile()`(`category_scores` → `rank_products`/`build_pool` → 30개) → PostgreSQL(실행 기록 · 프로필 · 리뷰) → 7.7. LLM 호출 없음, 서버 따로 안 띄움. 시험 수신자 번호: 제외 모드 9,300,001~ · 감점 모드 9,310,001~(전후로 지움, `--keep`이면 남김).

| 비선호_위치 | 감점 모드에서 비선호 소분류가 전체 순위 몇 위에 있나(30위 안/밖) |

| 입력 | 이번에 쓴 시나리오 |

## 검사

**자동(모든 실행 13개):** 7.6 202 · 7.7 콜백 1회·경로·토큰 · 본문 계약(`ProfileCallbackRequest`, 모르는 필드 금지) · 개수 = min(30, 후보) · 중복 없음 · 카탈로그·재고 · **재현성**(콜백 30 = 실행 기록 30 = 같은 입력의 순위 앞 30) · 비선호(제외: 0개 / 감점: 비선호 아닌 상품 뒤에만) · **소분류 점수 독립 재계산**(리뷰·카탈로그에서 직접) · **점수 공식 독립 재계산**(인기 + 편향 + 감점, 오차 < 1e-9) · 저장된 점수 = 코드 점수 · 리뷰 행(중복 제거·자리·지문) · **원문 미저장**(리뷰 글·취향 문장이 DB 어디에도 없음) · 실행 기록 DELIVERED.

**시나리오 기대('기대' 시트):** `상위N_최소` · `상위N_최대` · `조회수순` · `모드간_동일` · `순위_앞섬`.

## 2026-10-12 실행

20건(10명 × 2모드) · 검사 300/300 통과 · 7.7 콜백까지 p50 ≈ 11ms · 전체 1.0초. **발견:** 리뷰에 양의 편향이 있는 6명 모두 30개를 그 소분류가 **전부** 차지한다. 원인은 정규화가 아니라 **선택성** — 30개는 카탈로그 4,231개의 0.7%인데 편향 +0.67 은 순위로 전체의 1/3을 끌어올리는 크기라, 편향 소분류 상품은 조회수 중간만 돼도 편향 없는 1위를 넘는다. 인기를 순위 백분위로 바꿔도(10-12) 결과는 같았다(지금 조회수는 고르게 퍼져 두 방식 값이 거의 같음). 가중치 · 소분류 상한 시뮬레이션과 결정할 것은 [docs/시나리오_검증_결과_2026-10-12.md](../../docs/시나리오_검증_결과_2026-10-12.md).
