## 5. 점검 방법 (다음에 또 할 때)

```bash
# 링크·그림 참조가 살아 있는지 + 아무도 안 쓰는 그림이 있는지
python3 - <<'EOF'
import re, pathlib
root = pathlib.Path(".")
mds = [root/"README.md", root/"이름_대조표.md"] + sorted(root.glob("docs/**/*.md")) + sorted(root.glob("tools/**/README.md"))
used = set()
for md in mds:
    for label, tgt in re.findall(r"!?\[([^\]]*)\]\(([^)]+)\)", md.read_text(encoding="utf-8")):
        if tgt.startswith(("http", "#")): continue
        p = (md.parent / tgt.split("#")[0]).resolve()
        if not p.exists(): print("깨짐:", md, "→", tgt)
        elif p.suffix == ".png": used.add(p)
print("안 쓰는 그림:", sorted({p.resolve() for p in root.glob("docs/**/*.png")} - used))
EOF

uv run pytest -q          # 문서에 적힌 수와 같은지
uv run ruff check src tests tools alembic
```

그림은 **소스에서 다시 그린다** — `docs/assets/build_*.py`(구조·클래스·흐름·지도·DB 전환) · `build_be_sequences.py`(필드표 v1·v2·v3 · 시퀀스_전체 · DB_ERD 안의 mermaid).
