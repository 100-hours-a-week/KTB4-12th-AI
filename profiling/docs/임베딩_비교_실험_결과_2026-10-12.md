## 6. 고친다면(제안 — 코드는 바꾸지 않음)

1. **후보에 인기 상위를 섞기:** 태그 후보 ∪ S0 앞 100. U06 · U10 의 편중과 인기 손실을 줄인다.
2. **유사도 항을 넣으면 감점도 키우기:** 감점 ≤ −(유사도 가중 + 최대 편향), 즉 −4.0. 또는 태그 대상이 비선호인 태그는 질의에서 빼기(U09 A 의 엉뚱한 결과도 막음).
3. **MMR 관련도를 순위 백분위로 정규화:** 감점 상품이 다른 사람 결과를 흔드는 부작용을 없앤다. λ 는 0.5.
4. **상품명 기반 근접 중복 제거:** 같은 브랜드 + 같은 모델 코드면 하나만 남긴다.
5. **모호한 특징 태그의 가중 낮추기:** "실용적인 선물"처럼 거의 모든 선물에 맞는 태그는 질의 가중을 줄이거나 후보 수를 줄인다. 태그 추출 프롬프트 유의사항에 넣을 항목이다.
6. 1~5 를 넣고 다시 비교: 하네스 기대에 "U09 뷰티 0", "한 소분류 최대 K", "근접 중복 0" 추가.
